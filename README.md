# 🛢️ Drillix — Система AI-подбора КНБК

**Drillix** — это веб-приложение для инженеров-технологов буровых компаний, которое автоматизирует процесс подбора компоновки низа бурильной колонны (КНБК) с помощью искусственного интеллекта.

Приложение позволяет вести учет скважин и секций бурения, хранить справочник оборудования и генерировать рекомендации по КНБК на основе больших языковых моделей (LLM), строго опираясь на физические параметры секции и доступный каталог инструментов.

## 🚀 Ключевые возможности

- **Управление скважинами и секциями:** Удобный интерфейс для создания, редактирования и удаления скважин, а также добавления секций с валидацией глубин и параметров.
- **Справочник оборудования:** Полноценный CRUD для ведения базы инструментов (долота, ВЗД, УБТ, телесистемы и т.д.) с фильтрацией по диаметру.
- **AI-генерация КНБК:** Интеграция с нейросетью (через Bothub API, модель DeepSeek). ИИ анализирует условия бурения, траекторию и подбирает подходящее оборудование из базы.
- **Умный промптинг и валидация:** Система заставляет ИИ возвращать строго структурированный JSON, а бэкенд валидирует ответ (проверка на наличие долота, проверка существования ID оборудования).
- **Аудит генераций:** Сохранение сырого ответа нейросети (rawAiResponse) и названия модели для прозрачности и отладки.
- **Редактирование КНБК:** Возможность вручную скорректировать состав компоновки (изменить порядок, заменить элементы из базы или добавить свободные позиции).
- **Ролевая модель:** Разделение доступа на Администратора (управление пользователями и справочником) и Технолога (работа со скважинами и генерациями).
- **Статусы рекомендаций:** Жизненный цикл КНБК (Черновик → Согласована / Отклонена).

## 🛠️ Стек технологий

**Бэкенд:**
* Java 21
* Spring Boot 3.x
* Spring Security (Basic Auth)
* Spring Data JPA / Hibernate
* H2 Database (для разработки) / MariaDB (для продакшена)
* Java 11 HttpClient (для интеграции с Bothub API)

**Фронтенд:**
* Vanilla JavaScript (ES6+)
* HTML5 / CSS3 (кастомная верстка без тяжелых фреймворков)
* Fetch API для работы с REST-эндпоинтами

**Инфраструктура:**
* Docker / Docker Compose
* Swagger / OpenAPI 3 для документации API
